# CDC_Diabetes_Health_Indicators

• Analyzed the distribution of diabetic status and conducted significance testing to identify key features influencing an
individual's diabetic condition

• Developed a predictive model capable of accurately classifying individuals into three categories: diabetic, pre-diabetic, or
healthy, using demographic, lifestyle, and health-related factors

• Implemented three machine learning models to predict diabetic status based on variables such as BMI, age, physical activity,
high cholesterol, and alcohol consumption
